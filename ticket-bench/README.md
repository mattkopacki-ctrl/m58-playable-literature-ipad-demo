# Ticket Bench

A tiny web app that averages two numbers. Python 3.8+ standard library only — no dependencies.

## Run

```bash
cd ticket-bench
python3 -m ticket_bench.server 8000
```

Open http://127.0.0.1:8000/, enter two numbers, and click **Calculate average**.

## Test

```bash
cd ticket-bench
python3 -m unittest -v
```
